# Problem Alignment

Requirements traceability for Challenge 6, Urban Air Quality Assistant: each clause of the brief, the feature that answers it, the code and the tests.

> Create a GenAI-powered assistant that helps families and communities navigate severe winter smog and urban air pollution. The application should suggest low-emission daily routines, indoor air quality hacks, and sustainable alternatives tailored to their location and lifestyle, while clearly explaining the direct impact of their choices.

## What the challenge explainer asked for

| Ask                                      | Answer                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| Real-time data, with its source and time | CPCB station, distance and IST timestamp on screen; "Modelled" label when no station is near |
| Never let the AI make up air numbers     | The number guard; the AI only words code-computed facts                                      |
| Any location in India                    | Station and place search, or device location                                                 |
| Morning / afternoon / evening plan       | Sections from "This morning" to "Tomorrow morning"                                           |
| The "why" and the impact of each choice  | On every tip                                                                                 |
